# Apply Terraform Configuration

This repo is a companion repo to the [Apply Terraform Configuration tutorial](https://developer.hashicorp.com/terraform/tutorials/cli/apply).

## My notes
- `terraform apply` makes the planned changes and updates the state file
- `terraform destroy` removes everything the config created
- State tracks what Terraform manages, so never edit it by hand
